# OL-R1 — 7-Course Renaissance Lute

**OpenLute Renaissance Design 1 — 7-Course**

OL-R1 is the first Renaissance lute design developed as part of the OpenLute project.

This design is intended to provide a playable, reproducible lute that can be fabricated using commonly available 3D-printing equipment and materials.

## Status

**Experimental**

OL-R1 is an experimental design that is being actively built and tested. Dimensions, materials, construction methods, and other aspects of the design may change as testing and development continue.

Builders are encouraged to share their experiences, identify problems, and suggest improvements.

## About the Design

OL-R1 is designed around the construction of a Renaissance-style lute while taking advantage of modern digital fabrication.

The design files in this directory represent the current development of the 7-course configuration.

The design is intended to be:

* 3D printable
* Reproducible by other builders
* Open to modification and experimentation
* Documented sufficiently for others to build and evaluate

## Design Files

Design files for OL-R1 will be organized within this directory.

As the project develops, files may include:

* **CAD source** — editable source design files
* **Printable files** — STL or other manufacturing-ready files
* **Documentation** — build and assembly information
* **Print settings** — recommended manufacturing parameters
* **Hardware** — required hardware and components

See the individual directories for the current files and documentation.

## Building OL-R1

A complete build will require more than the printed components.

Builders should expect to use appropriate:

* Filament and other materials
* Strings
* Hardware
* Adhesives
* Tools
* 3D-printing equipment

Detailed requirements and build instructions will be documented as the design progresses.

## Development

OL-R1 is developed through a combination of CAD design, physical prototyping, testing, and community feedback.

If you build an OL-R1, feedback and build experience are valuable contributions to the project.

Please see the main repository's [CONTRIBUTING.md](../../../CONTRIBUTING.md) for information about contributing.
