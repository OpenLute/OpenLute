# OL-R1 — Hardware & Materials

This document lists hardware and materials currently used or recommended for the OL-R1 7-course Renaissance lute.

The OL-R1 design is experimental, and specific components may change as the design develops.

## Tuning Machines

The OL-R1 pegbox is currently designed around ukulele-style tuning machines.

**Current design reference:**

[Ukulele Tuning Machines — Amazon](https://www.amazon.com/dp/B0CKXYDDBK)

The pegbox geometry is designed around this style of tuner. If substituting different tuning machines, verify mounting dimensions and clearance before modifying or printing the pegbox.

## Strings

A 7-course lute string set is recommended.

### La Bella TL 7CRS #1

[La Bella TL 7CRS #1 — 7 Course Lute Strings](https://www.stringsbymail.com/la-bella-tl-7crs-1-lute-strings-7-course-full-set-4968.html)

This is the primary string set used/recommended for the current OL-R1 design.

### Alternate 7-Course Set

[7-Course Lute Strings — Amazon](https://www.amazon.com/dp/B004I4DT7U)

When using an alternative string set, select a set appropriate for a similar scale length and tuning. Different string materials and gauges can change the tension and response of the instrument.

## Pegbox Reinforcement Rod

The current OL-R1 design uses a **1/4-inch diameter steel rod** to reinforce the pegbox and neck.

### Rod Requirements

* Diameter: **1/4 inch**
* Pegbox section: **7 1/8 inches**
* Neck sections: **2 × 1 3/8 inches**

The 7 1/8-inch section is installed inside the pegbox reinforcement shaft and secured with epoxy.

The two 1 3/8-inch sections are used when joining the pegbox to the neck. These sections should be installed during the pegbox-to-neck assembly rather than during the initial pegbox reinforcement.

## Adhesive

Epoxy is currently used for the primary structural joints of the instrument, including:

* Bowl halves
* Soundboard halves
* Soundboard braces
* Soundboard-to-bowl connection
* Pegbox reinforcement rod
* Pegbox-to-neck reinforcement

### Recommended Epoxy

The current OL-R1 build uses **J-B Weld ClearWeld Quick-Setting Epoxy**.

[J-B Weld ClearWeld Quick-Setting Epoxy — Amazon](https://www.amazon.com/J-B-Weld-50240-ClearWeld-Quick-Setting/dp/B07TTTYKGS)

This is the epoxy used during development and testing of the current design.

A suitable alternative epoxy may be used, but builders should select an adhesive appropriate for the intended joint and follow the manufacturer's instructions for mixing, application, and curing.

## Optional Strap Handle

An optional strap handle can be installed at the end of the bowl.

The strap handle is not required for the basic OL-R1 build.

See the build guide for installation information.

## Notes

The components listed here represent the current OL-R1 build configuration. As the design is tested and refined, specific hardware and materials may be updated.

Where possible, future revisions will document both the component specification and suitable alternatives so builders are not dependent on a single supplier or product.
