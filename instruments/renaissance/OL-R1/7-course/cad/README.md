# CAD Source

This directory contains the editable Fusion 360 source files for OL-R1.

The primary source file is:

* `OL-R1-7-course.f3d`

## Current CAD Structure

The current design was developed as a single Fusion 360 timeline rather than as a fully component-based assembly.

The individual bodies are named to make the design easier to understand and work with, but the overall model has not yet been reorganized into separate components.

This reflects the current state of development and the way the design was originally created.

## Future Development

A future improvement would be to reorganize the design into a more conventional component-based Fusion 360 assembly.

This could make the design easier to:

* Modify individual parts
* Reuse components
* Develop alternate configurations
* Manage different instrument designs
* Contribute changes to specific parts of the design

**CAD restructuring is a potential contribution opportunity.** If you have experience with Fusion 360 assemblies and would like to help improve the organization of the OpenLute CAD source, contributions are welcome.

The existing parametric timeline should be preserved where practical during any restructuring.
