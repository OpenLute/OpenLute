# Printable Files

This directory contains the current printable STL files for the OL-R1 7-course Renaissance lute.

These files are generated from the CAD source and are intended for use with a 3D printer.

For the editable design source, see the [`cad`](../cad/) directory.

For recommended printing parameters, see the [`print-settings`](../print-settings/) directory.

For assembly instructions and required hardware, see the [`documentation`](../documentation/) directory.

## File Naming

STL files use the following naming convention:

`OL-R1-<Part>.stl`

For example:

`OL-R1-Bowl-Top.stl`

The course configuration is established by the directory containing the files, so it is not repeated in each filename.

## Tested Printing Environment

The current OL-R1 printable files have been developed and tested using a **Qidi Plus4** 3D printer with **Qidi Studio** slicing software.

Other printers and slicers may require adjustments to print settings. See the [`print-settings`](../print-settings/) directory for additional information.

## Current Status

The OL-R1 design is **experimental**. Printable files may change as the design is tested and refined.

When using an STL, check the repository history and current release information to ensure you are using the intended version.
